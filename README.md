# openclaw-bridge

[![CI](https://github.com/joshmrtn/openclaw-bridge/actions/workflows/ci.yml/badge.svg)](https://github.com/joshmrtn/openclaw-bridge/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Bridges SillyTavern characters to OpenClaw so your AI companions maintain a
single canonical identity across every channel. SillyTavern is the brain
(character cards, lorebooks, LLM pipeline). OpenClaw is the body (Discord,
Telegram, autonomous scheduled actions).

---

## Who this is for

Most tools that connect SillyTavern and OpenClaw treat the relationship as a
one-way migration — they import ST characters *into* OpenClaw so you can leave
SillyTavern behind:

- [openclaw-tavern](https://github.com/garfeildma/openclaw-tavern) — imports ST characters into OC's agent system
- [sillytavern-cards-skill](https://github.com/pearyj/sillytavern-cards-skill) — an OC skill that loads ST character cards for use within OC

If that is what you need, those tools are the right choice.

**openclaw-bridge takes the opposite approach.** SillyTavern stays the
authoritative brain: every message, regardless of which channel it arrives on,
is generated by ST's full pipeline — character cards, lorebooks, author's notes,
persona, token budgeting — and written back to ST's chat history. OpenClaw
handles the channel layer but never owns the character.

## Quick start

**Prerequisites:** bash, Node.js 22+, python3

```bash
git clone https://github.com/joshmrtn/openclaw-bridge.git
cd openclaw-bridge
./setup.sh
```

`setup.sh` finds your SillyTavern installation, copies the plugin and extension
into it, generates a bridge auth token, and installs the OC gateway plugin.
Pass `--st-path ~/SillyTavern` to skip the interactive prompts.

Full first-time instructions: **[Getting started](docs/getting-started.md)**

## Updating

When a new version is available, pull it and redeploy in one step:

```bash
./update.sh
```

`update.sh` pulls the latest changes, recompiles the OC plugin, runs any pending
data migrations, and copies the updated plugin and extension into SillyTavern.
After it finishes, restart SillyTavern and the OpenClaw gateway.

`update.sh` remembers the SillyTavern path you used during setup — no prompts on
subsequent runs. If your SillyTavern installation has moved, pass `--st-path`:

```bash
./update.sh --st-path ~/SillyTavern
```
